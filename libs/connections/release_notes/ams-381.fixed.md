`regex` / `iregex` lookups now work on SQLite. Every SQLite connection, sync and async, registers a `REGEXP` function on Python `re`, as Django does: a NULL pattern or value matches nothing, any other value is matched as text. Before, every such query failed with `no such function: REGEXP`. PostgreSQL is unchanged. The pattern reaches the database as written; `docs/regex-lookups.md` lists where PostgreSQL's engine differs from Python `re` and how to write a pattern that gives the same rows on both. (ams-381)
