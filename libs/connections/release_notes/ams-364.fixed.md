On SQLite, a string stored in a `JSON`/`JSONB` column as a typed JSON value (`Value(x, output_type=JSONB)`) reads back as the same string. Before, a numeric-looking string such as `'123'` read back as the number `123`. Such a string, or one starting with `"`, is now stored as its JSON text (`'"123"'`), and filters compare it in that form. Rows saved earlier keep their stored number, and a filter by the string no longer matches them. Reading decodes that form in any column, so a text stored as exactly a quoted number, such as `"42"` with the quotes, now reads back as `42`.
